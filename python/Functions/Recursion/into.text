Agar main ye code likhu
def hello(n):
    if n == 0:
        return

    print("Hello", n)

    hello(n-1)

    print("Back", n)

hello(2)

Output kya hoga?

Hello 2
Hello 1
Back 1
Back 2
Kyon?

Jab hello(0) return hua to control hello(1) mein hello(n-1) wali line ke baad aaya.

Isliye

print("Back",1)

chala.

Fir hello(1) khatam.

Fir control hello(2) mein hello(n-1) ke baad aaya.

Fir

print("Back",2)

chala.

🔥 Golden Rule

Return kabhi bhi usi function ke andar wapas nahi aata jisne return kiya hai.

Return caller function ke paas aata hai.

Yani:

hello(2)
   │
   └── hello(1)
          │
          └── hello(0)
                 │
              return
                 │
                 ▼
          hello(1)  ← yahan wapas
                 │
              finish
                 ▼
          hello(2)  ← fir yahan wapas
